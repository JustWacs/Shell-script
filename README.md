# Sistem Manajemen File Linux (Shell Script)

---

## List Fitur

1. **Tampilkan direktori aktif** (Menggunakan perintah dasar `pwd`)
2. **Tampilkan isi direktori** (Menggunakan perintah dasar `ls -F`)
3. **Buat folder baru** (Menggunakan perintah dasar `mkdir`)
4. **Buat file baru** (Menggunakan perintah dasar `touch`)
5. **Salin file** (Menggunakan perintah dasar `cp`)
6. **Pindah / Rename file** (Menggunakan perintah dasar `mv`)
7. **Hapus file / folder** (Menggunakan perintah dasar `rm` dan `rm -r`)
8. **Keluar dari program**

---

## Installation Guide

### Menggunakan Git Bash

1. **Install Gitbash:**
   - Download installer [git-scm.com](https://git-scm.com/downloads).
2. **Clone Repositori:**
   - Buka dengan gitbash pada suatu directory.
   - Clone repositori.
   ```bash
   git clone git@github.com:JustWacs/Shell-script.git
   cd Shell-script
   ```
3. **Buka Folder:**
   - Masuk ke folder
   ```bash
   cd Shell-script
   ```
   - Run project
   ```bash
   bash manajemen-file.sh
   ````
